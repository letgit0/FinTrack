# 💰 Personal Finance Tracker (MERN Stack)

A full-stack personal finance tracking application built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
This application helps users track income and expenses, categorize transactions, and visualize their financial status through a clean dashboard.

---

## 🚀 Features

### 🔐 User Authentication
- Secure authentication system using **Clerk**
- Supports multiple login methods:
  - Google
  - GitHub
  - Facebook
  - Twitch
- Protected routes for authenticated users

---

### 💸 Transaction Management (CRUD)
- Add income and expense records
- Edit existing transactions
- Delete transactions
- View all transaction history in a structured format

---

### 📊 Dynamic Dashboard
- Real-time financial summary
- Displays:
  - Total income
  - Total expenses
  - Current balance
- Automatically updates based on user transactions

---

### 🏷️ Categorization System
- Assign categories to each transaction
- Supports payment methods tagging
- Helps in better financial tracking and analysis

---

## 🛠️ Tech Stack

### Frontend
- React (with TypeScript)
- Vite
- React Router
- Context API

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose (ODM)

### Authentication
- Clerk
